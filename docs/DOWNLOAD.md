# Скачивание программы: Chrome ругается на «вирус» — что делать

## Почему так происходит
Chrome (Safe Browsing) и Windows SmartScreen блокируют **любой редкий,
неподписанный .exe**, скачанный не из магазина приложений. У `RetailBreakEven.exe`
нет платной подписи разработчика (code signing), а сам файл: открывает браузер,
поднимает локальный сервер и собран Go с флагом `-H windowsgui` — для эвристик
антивирусов это «подозрительный» набор, хотя в исходном коде (он весь в этом
репозитории) ничего вредоносного нет. Это **ложное срабатывание**.

Проверить самостоятельно: загрузите .exe на https://www.virustotal.com —
и сверьте SHA-256 с файлом `SHA256SUMS.txt` из того же релиза.

## Откуда качать (по надёжности)
1. **Releases** (лучший вариант): https://github.com/slchumak75-sketch/analitika1/releases
   → `RetailBreakEven-Windows.zip` из последнего релиза.
2. Actions → последний зелёный прогон `build` → Artifacts (нужен вход в GitHub).

## Если Chrome заблокировал скачивание
1. Нажмите `Ctrl+J` (страница загрузок).
2. У заблокированного файла: `⋮` (или стрелка) → **«Сохранить» / «Keep» /
   «Всё равно сохранить»** (в новых версиях: «Разрешить загрузку»).
3. Если ругается уже при запуске — Windows SmartScreen:
   **«Подробнее» → «Выполнить в любом случае»**.

## Если не хотите ничего «разрешать» — соберите сами из исходников
Так .exe вообще не скачивается из интернета, а собирается у вас:
1. `<> Code → Download ZIP` на GitHub (в этом архиве нет .exe — Chrome его не блокирует).
2. Установите Go: https://go.dev/dl/
3. Распакуйте и запустите `build.bat` — получите свой `RetailBreakEven.exe`
   (тесты + сборка, интернет не нужен).
