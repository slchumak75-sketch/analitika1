## Правила проекта
- Зависимости НЕ добавлять без нужды: программа ценна тем, что один .exe, stdlib only, офлайн.
- Вся расчётная логика — только в `calc.go` (`Compute`), GUI — только отображение.
- Любое изменение формул → тест в `calc_test.go` с ручным пересчётом в комментарии.
- После правок `versioninfo.json`/`icon.ico` — перегенерировать `resource_windows_amd64.syso`.
- Каждое значимое изменение: запись в `CHANGELOG.md` + обновление этого файла.
