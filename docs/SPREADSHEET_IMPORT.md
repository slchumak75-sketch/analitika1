# Импорт и анализ таблиц (.xls / .xlsx / .csv)

_Добавлено 2026-10-19 по файлу «ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xls»._

## Анализ исходного файла (образец: samples/ОТЧЕТ ПО ОРГАНИЗАЦИИ мир.xls)
Настоящий Excel 97-2003 (OLE2/BIFF), 1 лист «Лист1», 45×8: организация
**МИРСТРОЙМАРКЕТ**, периоды — кварталы 1–3 + «Итого» (4 кв. пуст).
Структура: налоги → выручка (ККМ + накладные) → НДС → себестоимость реализации →
«Себестоимость затрат» (итог) → детальные статьи затрат (фонд з/пл, ФСН, аренда,
коммунальные, транспорт, банк и т.д.). Сумма детальных статей сходится с итогом
затрат до копейки (245 389,90) — классификация анализатора это учитывает.

Ключевые цифры за 3 квартала (пересчитано и сверено вручную):
| Показатель | Значение |
|---|---|
| Выручка | 1 468 005 (1кв 258 823 → 3кв 623 143, рост) |
| Себестоимость реализации | 866 034 (59,0% выручки) |
| Валовая прибыль / маржа | 601 971 / **41,0%** (стабильна по кварталам: 41,0 / 41,1 / 40,9%) |
| Затраты (накладные) | 245 390 (16,7% выручки) |
| Прибыль до налогов | 356 581 (24,3%); после налогов (НДС к уплате 57 002 + прибыль 23 341) ≈ 276 239 |
| Крупнейшие статьи | фонд з/пл 120 923 (49,3% затрат), ФСН 41 995 (17,1%), банк 13 333, аренда 12 113 |

Выводы: маржа стабильна, выручка растёт, главная статья — ФОТ с отчислениями
(66,4% всех затрат) — первый кандидат на оптимизацию в калькуляторе ТБУ.
Второй файл (`версия 2.xls`) — тот же отчёт шире: 2 организации бок о бок и помесячные
блоки; анализатор берёт первый найденный блок периодов на листе (см. ограничения).

## Что умеет программа теперь
- Карточка **«Импорт таблицы»** в интерфейсе: открыть `.xls`, `.xlsx`, `.csv/.tsv`
  (кнопка или `/api/import`, multipart, лимит 16 МБ).
- Парсеры — только stdlib Go (`spreadsheet.go`): XLSX = zip+XML; XLS = собственный
  разбор OLE2+FAT и записей BIFF8 (SST, NUMBER, RK, MULRK, LABEL, FORMULA);
  CSV = разделитель `;`/`,`/Tab, UTF-8 или windows-1251.
- Анализ (`report.go`): находит строку периодов (кв/мес/итого), колонку названий
  и организацию; классифицирует строки (выручка, себестоимость, итого затрат,
  налоги, НДС, прочие статьи); считает итоги, средние, доли выручки/затрат,
  тренд первый→последний период, KPI (маржа, прибыль до/после налогов),
  топ-10 статей, предупреждения (пустые периоды, нет выручки) и рекомендации.
- Кнопка **«В расчёт безубыточности»**: среднемесячные выручка и статьи затрат
  (итог ÷ месяцы покрытия; квартал = 3 мес.) подставляются в калькулятор ТБУ.

## Баги, найденные сквозным тестом на реальном файле (уже исправлены)
1. BOF BIFF: тип потока читался со смещения 0 вместо 2 — .xls вообще не парсился.
2. `isPeriodHeader`: «МИРСТРОЙ**МАР**КЕТ» ложно считался периодом («мар»=март) —
   месяцы теперь матчатся только как слово/сокращение с точкой.
3. Классификация: «Реализация (Накладные)» попадала в расходы; а после расширения
   правила выручки «Себестоимость реализация» уходила в выручку — важен порядок:
   себестоимость проверяется раньше выручки.

## Ограничения (для следующего агента)
- .xls: только BIFF8 (Excel 97-2003); строки SST, разрезанные CONTINUE по границе
  символа, — упрощённая склейка; формулы берутся по кэшированному значению.
- На листе анализируется первый блок периодов; «две организации бок о бок»
  (версия 2) полностью не раскладывается — доработка: искать несколько блоков.
- Тесты: `spreadsheet_test.go` (фикстура, повторяющая структуру файла «мир»,
  CSV, минимальный XLSX, RK-декодер). Реальный .xls парсится тем же кодом;
  образцы лежат в `samples/` для ручной проверки.
