Десктопная программа для **Windows** на **Go** с **HTML-интерфейсом**.
Один файл `RetailBreakEven.exe` — без установки, без интернета и без внешних зависимостей.

## Скачать готовый .exe

Страница релизов: https://github.com/slchumak75-sketch/analitika1/releases → `RetailBreakEven-Windows.zip`. Если Chrome/SmartScreen ругаются на «вирус» — это ложное срабатывание на неподписанный файл, пошагово: `docs/DOWNLOAD.md`.

## Как пользоваться

1. Запустите `RetailBreakEven.exe` — интерфейс сам откроется в вашем браузере
   (программа поднимает локальный сервер на `127.0.0.1`, наружу ничего не отправляет).
2. Введите выручку, наценку (или маржу), средний чек и статьи расходов.
   Все суммы — за месяц. Расчёт обновляется автоматически при каждом изменении.
3. Изучите точку безубыточности, запас прочности и рекомендации.
4. Ползунками «снизить статью на %» соберите сценарий оптимизации накладных расходов
   и посмотрите, как сдвинутся точка безубыточности и прибыль.
5. Работа завершается кнопкой **«⏻ Завершить программу»** в интерфейсе.
   Введённые данные автоматически сохраняются (localStorage браузера);
   кнопка «Сохранить (JSON)» делает файл-копию для переноса на другой ПК.

> Если Windows SmartScreen покажет предупреждение для неподписанного файла:
> «Подробнее» → «Выполнить в любом случае». Программа собрана из исходников в этой папке.

## Что считает программа

| Показатель | Формула |
|---|---|
| Валовая маржа из наценки | `Наценка / (1 + Наценка)` |
| Коэффициент маржинальной прибыли | Валовая маржа − переменные расходы, % выручки |
| **Точка безубыточности** | Постоянные + накладные / Коэф. маржинальной прибыли |
| Точка безубыточности в чеках/день | (ТБУ / рабочих дней) / средний чек |
| Запас финансовой прочности | (Выручка − ТБУ) / Выручка × 100% |
| Выручка для целевой прибыли | (Постоянные + Целевая прибыль) / Коэф. маржинальной прибыли |
| Операционный рычаг | Маржинальная прибыль / Прибыль |

Дополнительно: P&L за месяц, график безубыточности, сравнение каждой статьи накладных
расходов с отраслевым нормативом (% выручки), резерв экономии, сценарии оптимизации
(ползунки и «довести до нормативов»), чувствительность прибыли к выручке ±20%,
автоматические рекомендации по статьям (аренда, ФОТ, коммунальные, реклама и др.).
Валюты: BYN, RUB, KZT, USD, EUR. Нормативы можно редактировать под свой формат магазина.

## Импорт таблиц отчётов

Карточка «Импорт таблицы» открывает отчёты вида «ОТЧЕТ ПО ОРГАНИЗАЦИИ …» (`.xls`, `.xlsx`, `.csv`): периоды, выручка, себестоимость, статьи затрат, маржа, тренды, рекомендации и перенос среднемесячных данных в калькулятор. Подробно: `docs/SPREADSHEET_IMPORT.md`, образцы — в `samples/`.

## Архитектура

* `main.go` — HTTP-сервер на `127.0.0.1` (свободный порт), открывает браузер,
  отдаёт встроенный HTML, эндпоинты `/api/calc`, `/api/health`, `/api/shutdown`.
* `calc.go` — вся расчётная логика на Go (интерфейс только отображает результат).
* `calc_test.go` — тесты на контрольных примерах (`go test ./...`).
* `web/index.html` — весь GUI одним файлом, встроен в бинарник через `go:embed`.
  Никаких CDN и внешних ресурсов — работает полностью офлайн.
* `icon.ico`, `versioninfo.json`, `resource_windows_amd64.syso` — иконка и версия .exe.

## Пересборка из исходников

Нужен только Go 1.21+ (https://go.dev/dl/).

**Windows (build.bat)** — просто запустите `build.bat`, либо вручную:

```bat
go test ./...
go build -trimpath -ldflags "-s -w -H windowsgui" -o RetailBreakEven.exe .
```

Флаг `-H windowsgui` прячет консольное окно. Для отладочной сборки с консолью
соберите без него: `go build -o RetailBreakEven.exe .`

**Кросс-компиляция с Linux/macOS (build.sh)**:

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath \
  -ldflags "-s -w -H windowsgui" -o RetailBreakEven.exe .
```

Если захотите заново сгенерировать ресурс с иконкой после правок `versioninfo.json`:

```sh
go run github.com/josephspurrier/goversioninfo/cmd/goversioninfo@latest \
  -64 -icon=icon.ico -o resource_windows_amd64.syso versioninfo.json
```

## Пример контрольного расчёта

Выручка 150 000, наценка 75% (маржа 42,86%), переменные 5,7% →
коэффициент маржинальной прибыли 37,16%. Накладные 53 000 →
**ТБУ = 53 000 / 0,3716 ≈ 142 637 в месяц** (4 755 в день, ≈73 чека в день при чеке 65),
прибыль ≈ 2 736, запас прочности 4,9%. Эти цифры заложены в «Пример данных»
и проверяются тестами аналогичной контрольной задачи.
